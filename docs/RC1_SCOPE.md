# DTAG v0.1.0-rc1 scope

Included:

- GSS 2022 female/male models
- GSS 2024 pooled model
- WVS7 pooled model
- Afrobarometer R1-R5 trained LSMs and maps
- interactive, one-question, and autoplay modes
- semantic fallback
- deterministic categorical-country conditioning where available
- WVS coordinate conditioning
- GSS polar-vector ideology tracking
- config-driven batch experiments and postprocessing

Not advertised as supported in RC1:

- Afrobarometer R6-R9 trained models
- Eurobarometer runtime models/maps
- automatic country/year-to-survey routing
- models regenerated with the newest manifest-based LSM training pipeline
