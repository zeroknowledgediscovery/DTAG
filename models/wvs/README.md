# WVS qnet models

Copy WVS qnet model files here, for example:

- `wvs7.pkl.gz`

WVS-style pooled models may include `A_YEAR`, `O1_LONGITUDE`, and `O2_LATITUDE`. If those features exist, `pipeline6iloc.py` can force year and country/continent context using `--year`, `--country`, and `--continent`.
