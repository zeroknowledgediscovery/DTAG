# DTAG divergent-quadrant question sets

These question sets are designed as diagnostic DTAG probes for the lower-right quadrant of the CM/WF shift plot:

- CM final-minus-initial ideology shift > 0
- WF final-minus-initial ideology shift < 0

That quadrant corresponds to both personas moving away from the ideological center: CM hardening rightward and WF hardening leftward.

The prompts are not intended as persuasion copy. They are structured survey-style probes for testing whether specific issue frames activate divergent latent dependencies in the LSM/DTAG state.

Recommended use:
1. Add these CSV files to your question-set directory.
2. Run the same forward, reverse, and shuffle controls.
3. Compare against existing convergence-producing sets.
4. Treat any lower-right movement as a hypothesis to validate across replicates, order variants, and model variants.
